# Marketing UI Kit · Wave Sports & Entertainment

The B-to-B marketing surface. Uses the *Wave Sports & Entertainment* primary lockup, dark canvas (`--night`), Volt as accent, brutalist hairline grid.

## Files
- `index.html` — interactive homepage (nav → hero → manifesto → originals grid → partners → footer).
- `Nav.jsx` — sticky top nav with backdrop blur.
- `Hero.jsx` — full-bleed editorial hero. Eyebrow + display headline + Volt key word + CTA.
- `Manifesto.jsx` — left-aligned eyebrow + serif pull quote + grid of stats.
- `OriginalsGrid.jsx` — 3-up show grid with poster cards.
- `Partners.jsx` — partner logo wall.
- `Footer.jsx` — directory footer with subsidiary lockups.

## Disclaimer
No production codebase or Figma was provided. This kit is a brand-faithful **invention**, not a recreation. Replace stub content (poster art, partner logos, photography) with real assets before production use.
