# Wave Originals UI Kit

Consumer-side OTT viewer for Wave Originals — documentaries, podcasts, talk, short-form. Click-through prototype: home → show hub → episode player.

## Files
- `index.html` — entry point. Boots `App.jsx`.
- `App.jsx` — full app (TopBar, FeaturedHero, ShowTile, Rail, ShowHub, Player). Six fake shows in `SHOWS`.
- `styles.css` — namespaced `.wo-` styles, imports `colors_and_type.css`.

## Disclaimer
No production codebase or Figma was provided. This kit is a brand-faithful invention. Photography, posters, and copy are placeholders.
